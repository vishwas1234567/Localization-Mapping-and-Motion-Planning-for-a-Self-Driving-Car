# Localization, mapping and motion planning for a self-driving car (2-D simulation)

VIO (EKF with stochastic cloning), LiDAR SLAM (NDT + pose graph), HD-map localization (NDT, particle filter),
behaviour trees vs FSMs, Hybrid A* and a Frenet state lattice. Pure NumPy/SciPy. Report: `main.pdf` / `main.tex`.

```
sdc_project/
|-- main.tex, main.pdf        report (Overleaf: compile main.tex with pdfLaTeX, run twice)
|-- numbers.tex, tables/      generated by make_tables.py from results/*.json
|-- make_tables.py            results/*.json -> numbers.tex + tables/*.tex
|-- run_all.py                unit tests + experiments E1-E9 + tables
|-- requirements.txt, FUTURE_IDEAS.md
|-- sdc/                      library
|   |-- geometry.py           SE(2) helpers, error metrics
|   |-- sim/                  world.py (route, tunnel, buildings), drive.py (trajectory, IMU/VO/GPS/LiDAR)
|   |-- localization/         vio.py, ndt.py, icp.py, pose_graph.py, lidar_slam.py, hd_map.py, particle_filter.py
|   |-- behavior/             bt.py (BT library), scenario.py (traffic scenario, BT + FSM controllers)
|   `-- planning/             dubins.py, hybrid_astar.py, scenarios.py, lattice.py
|-- experiments/              common.py, exp1_vio.py ... exp9_closed_loop.py
|-- tests/                    test_core.py
`-- results/                  *.json (raw numbers), figures/*.pdf|png
```

```
pip install -r requirements.txt
python run_all.py                 # everything; or run one experiments/expN_*.py, then python make_tables.py
# figures of E6/E8 can be redrawn from results/*.json:  python experiments/exp6_hybrid_sweep.py --replot
pdflatex main.tex && pdflatex main.tex
```

All experiments use fixed seeds. Results are simulation-only; see "Limitations" in the report.
